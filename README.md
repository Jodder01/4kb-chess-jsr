# 4KB Chess Engine

A compact Python chess engine developed for the Make.fun Tiny Chess bounty.

## Overview

This project contains a lightweight chess engine designed to play legal chess moves within the strict 4 KB source-code limit.

## Implementation

- Python-based chess engine
- Compact implementation
- Designed for competitive chess play
- Built and tested for the Make.fun Tiny Chess challenge

## Files

- `main.py` — Main chess engine
- `engine_v1.py` — Additional engine source
- `research.md` — Development notes
